# Changelog

## 0.2.0 - 2026-09-21

- Add `--strict` CI mode with warning-aware exit codes.
- Add standalone `--html` reports with inline CSS and escaped content.
- Add `repo-ritual.toml` custom checks and built-in check toggles.
- Add `.repo-ritual-ignore` support and improve secret hit context.
- Expand stack detection for modern ecosystems and frontend frameworks.
- Add a pull-request workflow that updates one GitHub comment with the report.
- Expand tests and documentation.
